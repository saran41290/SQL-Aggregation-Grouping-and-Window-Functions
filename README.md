# SQL Aggregation, Grouping, and Window Functions

This repository contains intermediate SQL practice focused on summarization, grouping, filtering aggregated results, and ranking.

## Project Overview
The exercises in this repository simulate reporting needs from an e-commerce business, such as top-priced products, sales summaries, grouped totals, and ranked outputs.

## Topics Covered
- ORDER BY
- LIMIT
- COUNT
- SUM
- AVG
- MIN
- MAX
- GROUP BY
- HAVING
- DENSE_RANK()

## Database Used
ECommerceDB

## Files Included
- `01_problem_statements/`
- `02_schema_and_setup/`
- `03_solutions/`

## Key Learning Outcomes
- Built summary reports using aggregate functions
- Grouped records for business reporting
- Filtered grouped results with `HAVING`
- Applied window functions for ranking
